# Pet Appetite Detective

Independent, privacy-first seven-day pet appetite observation proof of concept.

## Run
Node.js 20+; `npm start` then open http://localhost:4173. `npm test` runs the unit suite. No account or network needed.

## Demo
Load synthetic demo → review seven-day pattern → export observation JSON. Or enter your own daily observation.

# PRD — Pet Appetite Detective

Status: PROVISIONAL; review through official Devpost Learn Skill Pack.

## Jobs to be done
When my pet refuses food, help me log what happened so I can see a pattern instead of repeatedly switching food.

## Acceptance criteria
1. Enter day, appetite 0–3, stool and behavior notes.
2. Save and reload observations from localStorage.
3. Seven-day table shows all days, with explicit missing entries.
4. Summary calculates observed days and mean appetite, without medical interpretation.
5. Download JSON with clear demo disclaimer.
6. Synthetic demo reset never includes real user data.

## Safety
If pet is unwell or not eating, seek veterinary advice; app is not diagnostic.
